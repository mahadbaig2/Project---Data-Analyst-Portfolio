A management-focused Power BI solution for weekly store and department performance.

The project was designed around a CEO requirement for a simple, mobile-friendly reporting experience that could monitor weekly sales, compare current performance with the same period last year, calculate year-to-date values and track manager commissions.

Key Calculations & DAX Formulation

Deterministic business logic codified into robust DAX measures to support rapid visual recalculation and filter context preservation.

Weekly Growth Index Pacing Ratio

Calculates ratio of current week sales to prior year same week sales normalized to a 100 baseline.

Growth_Index = DIVIDE([Weekly Sales], [Sales_Same_Week_LY], 0) * 100
Formula: (Current Week Sales / Previous Year Same Week Sales) × 100
Year-to-Date (YTD) Sales Time Intelligence

Cumulative sales through the active calendar or fiscal week using canonical time intelligence.

YTD_Sales = TOTALYTD(SUM(Fact_WeeklySales[SalesAmount]), Dim_Date[Date])
Formula: Cumulative sales through current calendar/fiscal week using TOTALYTD / DATESYTD
Dynamic Store & Dept Tiering Ranking Logic

Dynamically tiers stores into top, median, and bottom tranches based on weekly revenue volume.

Store_Rank = RANKX(ALLSELECTED(Dim_Store[Store_Name]), [Weekly Sales],, DESC)
Formula: Ranked dynamic tiering using weekly sales volume without hardcoded partitions
Manager Commission Pool Incentive Policy

Allocates a 0.5% commission incentive strictly to store managers qualifying in the weekly top 5.

Manager_Commission = IF([Store_Rank] <= 5, [Weekly Sales] * 0.005, 0)
Formula: 0.5% of weekly sales allocated to managers of the top 5 performing stores

Solutions Architect Perspective

Future Scalability: Centralized Cloud Lakehouse Pipeline

While the weekly CSV drop provided an immediate, low-friction solution matching the organization’s current operational maturity, migrating this system to a centralized Azure Data Factory / Microsoft Fabric Lakehouse architecture represents the logical phase two.

Direct POS API Ingestion

Replacing manual file uploads with automated REST endpoints directly from point-of-sale registers eliminates human handling entirely.

Delta Lake Storage & ACID

Medallion architecture (Bronze → Silver → Gold) guarantees audit compliance, automated schema validation, and instantaneous rollbacks.

Direct Lake Mode in Power BI

Querying Parquet files directly from OneLake eliminates import refresh latency, enabling real-time intra-day sales pacing.
